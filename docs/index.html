PandABlocks is the open-source firmware and software stack behind PandABox. Wire FPGA functional blocks together at runtime to build triggering and position-capture logic — no rebuild, no recompile.

The idea

One firmware. Logic you wire like a patchbay.

A PandABlocks build ships dozens of FPGA functional blocks — clocks, counters, encoders, lookup tables, position capture. They sit on two shared buses, ready to connect.

You wire outputs to inputs over a simple TCP connection — from the web GUI, a script, or your control system. The signal path changes the instant you write it. The same firmware becomes a pulse generator, a position compare, a multi-axis trigger fan-out — whatever the experiment needs that day.

Because nothing is hard-wired, one image covers many applications, and a new FMC card just adds blocks — no rebuild of the server, client, or control layer.
